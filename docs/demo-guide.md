# 销售问数演示流程

演示目的：说明企业已有接口如何提供给 Agent 使用，并展示网关上的权限、内容检查和调用记录。销售数据全部虚构。

## 建议顺序（约15分钟）

| 步骤 | 平台操作 | 可以这样讲 |
|---|---|---|
| 1. 说明场景 | 展示三个销售查询接口 | 企业已有 API，不必重写业务逻辑，可以把接口接入 MCP 网关，供不同 Agent 使用。 |
| 2. OpenAPI 接入 | 新增 OpenAPI MCP，粘贴 Spec，配置后端地址和认证 | 网关按接口描述识别工具和参数，认证信息统一配置在服务端。 |
| 3. 实际查询 | Playground 先查数据说明，再查“2026年8月华东销售额”与环比 | 模型组织问题，工具读取业务数据，金额与环比由服务端计算。 |
| 4. 工具组合 | 创建 Virtual MCP，选择本演示所需工具 | 按应用用途提供工具入口，客户端不用逐个连接后端。 |
| 5. 权限对比 | 给测试成员/团队分配 Use 权限，用其自身身份调用 | 工具能否使用由调用身份与授权决定；不同成员使用自己的凭证，才能区分个人调用。 |
| 6. 内容检查 | 新建匹配 `2026-08` 的 Guardrail，并在 MCP Policy 的执行前阶段应用 | 这里演示对输入参数的拦截。命中内容规则与调用频率过高是不同问题。 |
| 7. 调用记录 | 打开 Request Traces，查看成功与拦截请求 | 展示当前角色可见范围内的调用身份、工具、状态与耗时；具体字段受日志配置影响。 |
| 8. 外部客户端 | 将 How To Use 提供的网关配置加入 MCP 客户端，再查相同问题 | 工具调用经过同一网关，沿用对应身份的授权和已配置策略。 |

菜单名称以当前工作区版本为准。初次演示优先把一条调用链跑通，HTTP MCP 和 Hosted STDIO 可作为补充接入方式展示。

## 固定问题与预期

1. “先告诉我这套销售数据有哪些月份和区域。” → 2026-07、2026-08；华东、华南、华北。
2. “2026年8月华东销售额是多少？” → 310,000.00元。
3. “和7月相比增长多少？” → 7月250,000.00元，增加60,000.00元，环比24.00%。
4. “查询2025年1月华东销售额。” → 无数据，不能回答为0元。

权限对比要使用新的请求，避免把客户端已有上下文或缓存回答误认为工具调用成功。检查实际工具调用记录，并在演示完成后恢复临时策略。

## 客户追问时的边界

- PII 脱敏需要选择相应检测器与处理动作，并用虚构样本验证；本仓库的月份正则拦截不能证明身份证识别、中文实体识别或提示词注入检测效果。
- 工具审批、工具访问申请、限流和熔断是不同流程。本 Demo 不包含 Agent 循环检测、请求速率限制或紧急断路器，相关能力应在目标平台版本中单独确认。
- 如还需演示 LLM 统一治理，可增加“供应商模型接入 → 分配 TFY 调用身份 → 预算/限流 → 查看日志”的独立环节。LLM 限流实验不能作为 MCP 工具限流的证据。
- 网关控制调用入口，不代替业务系统的数据权限、幂等处理和生产写入保护。
